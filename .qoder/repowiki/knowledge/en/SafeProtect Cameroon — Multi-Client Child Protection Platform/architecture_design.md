The repository is a flat monorepo of three sibling services — `backend-api` (Express + Prisma + TypeScript), `web-dashboard` (Next.js 14), and `mobile-app` (Expo/React Native) — that communicate exclusively over HTTP against the backend's `/api/*` routes. The root `package.json` declares workspaces for `backend-api` and `web-dashboard` and provides top-level scripts (`npm run backend`, `npm run web`, `npm run mobile`, `npm run install:all`) to bootstrap each client independently; the mobile app is installed separately because it depends on native tooling. All clients configure their base URL via environment variables (`NEXT_PUBLIC_API_URL` in the web dashboard, `EXPO_PUBLIC_API_URL` in the mobile app) so they can target the same local or LAN-hosted backend without hard-coded endpoints. A single MySQL 8 instance (bootstrapped via Docker Compose from the backend) plus Prisma migrations/seeds provide the shared data layer, and JWT access/refresh tokens with role-based access control form the cross-client authentication contract enforced uniformly by the backend middleware consumed by both frontends.
