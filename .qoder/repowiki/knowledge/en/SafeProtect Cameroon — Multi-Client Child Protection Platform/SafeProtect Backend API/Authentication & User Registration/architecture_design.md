Three-layer split inside the module: `routes/auth.routes.ts` declares Express `Router` endpoints (`/register`, `/login`, `/refresh-token`, `/forgot-password`) that delegate to `controllers/auth.controller.ts`; the controller performs all business logic — Prisma DB access via `../config/database`, password hashing/comparison via `../utils/password`, and JWT generation/verification via `../utils/token` — returning sanitized user objects (password stripped by a local `sanitizeUser` helper). `middleware/auth.ts` provides an `authenticate` guard that parses the `Authorization: Bearer <token>` header, verifies the access token with `verifyAccessToken`, and attaches the decoded payload to `req.user` (typed as `AuthRequest`). Dependency direction is one-way: routes → controllers → shared utils/config; the middleware is consumed by other route modules rather than imported here.
