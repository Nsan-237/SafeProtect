Two parallel feature modules (organizations, services), each split into a thin `routes/*.ts` file that mounts an Express `Router` and wires middleware, and a `controllers/*.ts` file that performs Prisma queries. Routes apply the shared `authenticate` middleware globally via `router.use(authenticate)` and then gate mutating routes with the `authorize([Role.ADMIN, Role.ORGIZATION])` RBAC middleware from `../middleware/rbac`. Controllers import the Prisma client directly from `../config/database` and use Prisma's `include`/`select` to eagerly load related entities (organizations include services/appointments; services include organization). The services controller enforces row-level ownership at the controller layer: ORGANIZATION users can only update/delete services belonging to their own organization, verified by cross-referencing `req.user.id` against `organization.userId`. Error handling is uniform — every handler wraps logic in try/catch and returns `{ error }` JSON on failure.
