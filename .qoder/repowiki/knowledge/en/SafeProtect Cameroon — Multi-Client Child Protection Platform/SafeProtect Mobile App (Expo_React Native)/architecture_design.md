The app is an Expo project bootstrapped from `App.tsx`, which wraps the tree in `SafeAreaProvider` + `AuthProvider` before mounting `RootNavigator`. Navigation is role-driven: `RootNavigator` reads the current user from `AuthContext` and renders either `AuthStack` (unauthenticated), `VictimTabs` (victim role), or `SocialWorkerTabs` (social worker role) using `@react-navigation/native` with stack/tab navigators. Screens are split by role under `src/screens/{auth,victim,socialworker}`. Shared UI lives in `src/components/shared` (cards, header, loading, SOS button, etc.). State is centralized via a React Context (`src/contexts/AuthContext`) that persists session data to `@react-native-async-storage/async-storage` and exposes login/logout/updateUser. All HTTP calls go through a single Axios instance in `src/services/api.ts` that injects Bearer tokens via request interceptors and handles 401 flows with refresh-token deduplication; auth failure callbacks trigger logout. Types for User, Case, Appointment, Service, Message are declared in `src/types/index.ts`. Styling uses NativeWind/Tailwind (`tailwind.config.js`, `nativewind-env.d.ts`).
